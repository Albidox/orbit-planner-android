## 5. Short Portfolio Pitch

Orbit Planner is a local/offline Android productivity MVP built to connect daily tasks with weekly, monthly, and yearly planning. It uses Kotlin, Jetpack Compose, Room, ViewModel-style data flow, and WorkManager to support real local persistence and a gentle daily reminder. Its differentiator is Rescue Mode, which helps users recover overdue incomplete tasks without shaming copy. The project is portfolio-ready as a local MVP and demonstrates phase-based Android development, manual QA, and honest documentation.

## 6. Demo Talking Script

One-minute demo script:

```text
Orbit Planner is a local/offline Android productivity MVP for planning daily work and connecting it to a bigger weekly, monthly, and yearly flow.

The problem I wanted to explore is that many to-do apps show today's list, but they do not always help users see how small tasks connect to longer-term goals. Overdue tasks can also feel stressful, so I built Rescue Mode to help users recover unfinished work gently.

In the demo, I would show the Today screen, add a task, mark it complete, then move through Week, Month, and Year Orbit to show how local tasks appear in planning summaries. I would also show Settings, where the daily pending-task reminder can be controlled and the app explains that data is stored locally with no cloud sync.

Technically, the MVP uses Kotlin, Jetpack Compose, Room, ViewModel and repository-style flow, WorkManager, Android notifications, and SharedPreferences. What makes the project different is the combination of local persistence, long-term planning summaries, and Rescue Mode for overdue work.
```
