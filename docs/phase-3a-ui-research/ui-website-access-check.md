## Best Free Sources To Use First

1. Material Design 3
2. Android Developers Material components and Compose Material 3
3. Behance
4. Dribbble
5. Figma Community free previews and free templates
6. Awwwards Mobile and Apps
7. Pinterest for mood keywords only

## Skip Or Limit For Now

- Skip Screenlane because the standalone public library does not appear usable.
- Skip paid/full-access areas of Page Flows, Pttrns, Nicelydone, Mobbin, and Refero.
- Avoid paid Figma templates and any template that requires a purchase or trial.

## Orbit Planner Research Takeaways

- Use official Material 3 and Android docs as the foundation so the future UI can map cleanly to Jetpack Compose and Material 3.
- Use Behance and Dribbble for mood, task card layouts, dark dashboard composition, progress rings, and empty-state inspiration.
- Use Pinterest only for broad mood-board keywords such as dark productivity app UI, orbit UI design, calm productivity aesthetic, and glow card UI design.
- Treat paid libraries as optional later references, not required research sources.
- Keep the visual direction calm, premium, futuristic, friendly, minimal, and emotionally supportive.
