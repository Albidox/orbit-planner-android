# Orbit Planner Android

Orbit Planner is a native Android productivity app that connects daily tasks with weekly missions, monthly focus, and yearly goals.

## Core Idea

Daily Task → Weekly Mission → Monthly Focus → Yearly Goal

## Special Feature

Rescue Mode helps users recover pending tasks without guilt.

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Room Database
- WorkManager
- Local Notifications
